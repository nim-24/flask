# Структуры данных Python

## Теория

Источник: [Python Tutorial — Data Structures](https://docs.python.org/3/tutorial/datastructures.html) и [Built-in Types](https://docs.python.org/3/library/stdtypes.html).

- **list (список)** — упорядоченная изменяемая последовательность. Элементы доступны по индексам; повторения разрешены. Полезные методы: `append()`, `remove()`, `pop()`, `sort()`. Список подходит, когда нужно хранить последовательность значений и менять её.

- **tuple (кортеж)** — упорядоченная неизменяемая последовательность. Элементы доступны по индексам, но после создания их нельзя заменить или удалить. Кортеж удобен для фиксированных данных, например координат.

- **dict (словарь)** — изменяемая структура, которая хранит пары «ключ — значение». По ключу можно найти соответствующее значение; ключи уникальны. Метод `.items()` позволяет перебирать пары ключей и значений. Словарь подходит для связанных данных, например названий товаров и их цен.

- **set (множество)** — коллекция уникальных элементов без доступа по индексам. Повторы автоматически убираются. Оператор `in` проверяет, входит ли элемент в множество. Для множеств доступны объединение `|`, пересечение `&` и разность `-`.

### Главное отличие

Список и кортеж хранят упорядоченные последовательности и поддерживают индексы. Список можно менять, а кортеж — нельзя. Словарь связывает ключи со значениями. Множество хранит только уникальные элементы и удобно для проверки принадлежности и операций над множествами.
